## 🚀 Características Principales

* 🔍 **Búsqueda Inteligente:** Filtros avanzados para encontrar vacantes por sector, ubicación y requisitos.
* 👤 **Gestión de Perfiles:** Espacio personalizado para que los candidatos gestionen su CV y postulaciones.
* 👔 **Panel de Reclutador:** Herramientas para publicar ofertas y dar seguimiento a los aspirantes.
* 📱 **Interfaz Limpia:** Navegación fluida sin distracciones visuales.

---

## 🛠️ Stack Tecnológico

El proyecto utiliza un stack moderno para garantizar escalabilidad y rapidez:

* **Frontend:** React Native + Expo.
* **Base de Datos:** Firebase.
* **Autenticación & Media:**  Supabase (PostgreSQL).
* **Herramientas de Diseño:** Photoshop, Paint Tool SAI 2 e Ilustración digital personalizada.
